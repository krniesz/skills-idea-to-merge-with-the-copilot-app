# Bookmark Manager Roadmap

A focused plan for making Mona's bookmarks easier to organize, update, and protect.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search & filter bookmarks | 🚀 | High |
| Editing | Edit a bookmark | 🚀 | High |
| Organization | Tags or folders | 🚀 | Medium |
| Portability | Import & export | 🚀 | Medium |
| Reliability | Duplicate slugs on re-add | 🐞 | Medium |
| Validation | Empty-URL validation | 🐞 | High |
| Data safety | Bookmarks lost when localStorage is cleared | 🐞 | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🏷️ Tags or folders — priority: medium
- 📦 Import & export — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL validation — priority: high
- ⚠️ Bookmarks lost when localStorage is cleared — priority: medium
